# v0.2 Periods, Filters, And Agent Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend v0.1 from daily-only collection to period-aware Product Hunt intelligence with weekly/monthly/yearly modes, richer official filters, local keyword filtering, and agent integration docs/templates.

**Architecture:** Add period/date-window and local filtering modules, extend config with period-specific quality settings and Product Hunt filter settings, extend the Product Hunt client to accept official `posts` filters, then wire CLI/collector/storage/report outputs around a `period + anchor date` request. Agent integration remains script-first in v0.2 with shared prompt templates and docs for WorkBuddy, Qclaw, Hermes, Codex, and Claude Code.

**Tech Stack:** Python stdlib (`dataclasses`, `datetime`, `calendar`, `enum`-like validation), existing `httpx` Product Hunt adapter, existing pytest suite.

---

## File Structure

- Create `src/ph_daily/periods.py`: period validation, date-window calculation, output key generation.
- Create `src/ph_daily/filters.py`: local include/exclude keyword filtering.
- Modify `src/ph_daily/config.py`: period-specific quality settings, Product Hunt official filters, local keyword filters.
- Modify `src/ph_daily/producthunt.py`: official `posts` query args (`featured`, `order`, `topic`, `url`, `twitterUrl`, `first`).
- Modify `src/ph_daily/storage.py`: period-aware output paths while preserving v0.1 daily paths.
- Modify `src/ph_daily/report.py` and `src/ph_daily/html_report.py`: period label in titles.
- Modify `src/ph_daily/collector.py`: period windows, period-specific thresholds, keyword filtering, official API filters.
- Modify `src/ph_daily/cli.py`: `--period`, `--topic`, `--featured`, `--order`, `--url`, `--twitter-url`.
- Modify `.env.example`, `README.md`, `docs/deployment-zh.md`.
- Create `docs/agent-integration-v0.2.md`: shared agent integration and prompt templates.
- Modify tests: config, period, filters, producthunt, storage/report, collector, CLI.

## Acceptance Criteria

- `ph-daily collect --period daily --date today` remains backward compatible.
- `ph-daily collect --period weekly|monthly|yearly --date YYYY-MM-DD` works.
- Daily output keeps v0.1 paths; non-daily output uses period-specific paths.
- Monthly defaults use votes >= 1000; yearly defaults use votes >= 5000.
- Product Hunt `featured`, `order`, `topic`, `url`, `twitterUrl` filters are supported.
- Local include/exclude keywords are supported.
- Agent docs cover WorkBuddy, Qclaw, Hermes, Codex, and Claude Code.
- `.venv/bin/python -m pytest -q` passes.
