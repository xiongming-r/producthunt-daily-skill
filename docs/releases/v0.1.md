# v0.1 Release Notes

Release date: 2026-05-12

## Summary

v0.1 is the first working version of Product Hunt Daily Agent Collector. It provides a reliable Python CLI for daily Product Hunt collection, dynamic quality filtering, OpenAI-compatible Chinese enrichment, JSON persistence, and Markdown/HTML reports.

## What Is Included

- Product Hunt API v2 GraphQL collection for daily launches.
- Dynamic quality filter:
  `votes >= MIN_VOTES` and `comments_count >= max(MIN_COMMENTS, ceil(votes * COMMENT_RATIO))`.
- OpenAI-compatible LLM enrichment with `LLM_BASE_URL`, `LLM_API_KEY`, and `LLM_MODEL`.
- Chinese explanatory analysis covering product purpose, target users, use cases, workflow examples, why it matters, and caveats.
- Raw JSON and processed JSON outputs.
- Chinese Markdown report output.
- Optional HTML report output through `OUTPUT_FORMATS=markdown,html`.
- CLI commands:
  - `ph-daily healthcheck`
  - `ph-daily collect --date today`
  - `ph-daily collect --date YYYY-MM-DD`
  - `ph-daily backfill --days N`
- Cloud cron deployment notes.
- Agent integration notes for tools that call the CLI.
- Bilingual README.

## Verification

Latest local verification before release:

```text
.venv/bin/python -m pytest -q
79 passed
```

## Known Limits

- v0.1 only supports date-based daily collection.
- Weekly, monthly, and yearly leaderboard collection are planned for v0.2.
- Agent tools can call the CLI, but deeper skill/agent execution adapters are planned for v0.2.
- LLM timeout retry and enrichment-only rerun are not implemented yet.
- No license has been selected.

# v0.1 版本说明

发布日期：2026-05-12

## 概述

v0.1 是 Product Hunt Daily Agent Collector 的第一个可运行版本。它提供一个稳定的 Python CLI，用于每日 Product Hunt 采集、动态质量筛选、兼容 OpenAI 格式的大模型中文解读、JSON 留存，以及 Markdown/HTML 报告输出。

## 已包含能力

- 使用 Product Hunt API v2 GraphQL 抓取每日发布产品。
- 动态质量筛选：
  `votes >= MIN_VOTES` 且 `comments_count >= max(MIN_COMMENTS, ceil(votes * COMMENT_RATIO))`。
- 兼容 OpenAI 的 LLM enrichment，支持 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。
- 中文解释型产品分析：产品用途、目标用户、使用场景、工作流示例、关注理由、注意事项。
- raw JSON 与 processed JSON 输出。
- 中文 Markdown 报告。
- 可选 HTML 阅读版报告：`OUTPUT_FORMATS=markdown,html`。
- CLI 命令：
  - `ph-daily healthcheck`
  - `ph-daily collect --date today`
  - `ph-daily collect --date YYYY-MM-DD`
  - `ph-daily backfill --days N`
- 云服务器 cron 部署说明。
- Agent 调用 CLI 的集成说明。
- 双语 README。

## 已知限制

- v0.1 只支持按日期采集日榜。
- 周榜、月榜、年榜采集计划在 v0.2 实现。
- Agent 当前主要通过 CLI 调用，深度 skill/agent 执行适配计划在 v0.2 实现。
