# v0.2 Release Notes

v0.2 expands the collector from daily-only reports into period-aware Product Hunt intelligence.

## Highlights

- Added `daily`, `weekly`, `monthly`, and `yearly` collection modes through `ph-daily collect --period ...`.
- Added period-specific quality thresholds. Monthly defaults to `MONTHLY_MIN_VOTES=1000`; yearly defaults to `YEARLY_MIN_VOTES=5000`.
- Added Product Hunt official `posts` filters: `featured`, `order`, `topic`, `url`, and `twitterUrl`.
- Added local include/exclude keyword filtering before LLM enrichment.
- Preserved v0.1 daily output paths while adding period-specific paths for weekly, monthly, and yearly reports.
- Added v0.2 agent integration docs and doc-only templates for WorkBuddy, Qclaw, Hermes, Codex, and Claude Code.

## Example Commands

```bash
ph-daily collect --period daily --date today
ph-daily collect --period weekly --date today
ph-daily collect --period monthly --date 2026-05-01
ph-daily collect --period yearly --date 2026-01-01
ph-daily collect --period monthly --topic artificial-intelligence --include-keyword agent
```

## Verification

```bash
.venv/bin/python -m pytest -q
```

# v0.2 版本记录

v0.2 将采集器从“只支持日榜”扩展为支持多周期的 Product Hunt 情报采集工具。

## 重点变化

- 通过 `ph-daily collect --period ...` 支持 `daily`、`weekly`、`monthly`、`yearly`。
- 增加按周期配置的质量阈值。月榜默认 `MONTHLY_MIN_VOTES=1000`，年榜默认 `YEARLY_MIN_VOTES=5000`。
- 增加 Product Hunt 官方 `posts` 过滤：`featured`、`order`、`topic`、`url`、`twitterUrl`。
- 增加本地 include/exclude 关键词过滤，在调用 LLM 前排除低相关产品。
- 保留 v0.1 日榜输出路径，同时为周榜、月榜、年榜增加周期化输出路径。
- 增加 v0.2 Agent 集成文档，以及 WorkBuddy、Qclaw、Hermes、Codex、Claude Code 的 doc-only 模板。

## 示例命令

```bash
ph-daily collect --period daily --date today
ph-daily collect --period weekly --date today
ph-daily collect --period monthly --date 2026-05-01
ph-daily collect --period yearly --date 2026-01-01
ph-daily collect --period monthly --topic artificial-intelligence --include-keyword agent
```
